Local Wildfire World viewer

This static page does not run or connect to a simulation. The former disconnected globe demonstration has been retired. Use the local viewer to inspect the real persistent World, fire footprint, resources, routes, and events.

Experimental research only. Synthetic inputs and suppression effects are not validated operational predictions. Do not use this tool for emergency dispatch.

Start the viewer

From the infernotactics repository directory, with the project's Python environment and viewer dependencies installed, run:

streamlit run src/viz/world_app.py

Then open the local World viewer. If Streamlit chooses a different port, use the local URL printed in your terminal.

  1. Choose synthetic illustrative inputs or a local validated scenario directory, then load/reset the World.
  2. Enter longitude and latitude and explicitly submit an ignition.
  3. Select a unit, operation, and projected target in the scenario CRS.
  4. Use Step or Run to horizon to advance time. Ordinary page reruns never advance the simulation.

The viewer displays input provenance and experimental validity labels. It requires no globe-service credential, remote simulation endpoint, or background polling from this page.
